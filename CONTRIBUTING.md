# Contributing

Padelpárbaj is a personal project. The repository is public only so that it can use GitHub's free tooling; it is not an open-source project and does not take outside contributions.

- **Issues and pull requests from outside the project are not accepted.** Interactions on this repository are limited to collaborators, and anything opened from outside may be closed without a reply.
- **A problem with the app** (padelparbaj.hu): use the feedback form in the app, or write to hello@padelparbaj.hu.
- **A security problem:** see [SECURITY.md](SECURITY.md). Please don't report it in public.
