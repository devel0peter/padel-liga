# Security

If you find a security problem in Padelpárbaj (padelparbaj.hu) or in this repository, please report it privately:

- on GitHub: the repository's **Security** tab → **Report a vulnerability** (private vulnerability reporting), or
- by email: hello@padelparbaj.hu.

Please don't open a public issue, and don't access, change or delete other people's data while looking. We'll answer as soon as we can.
